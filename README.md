# 學生加分小工具

一直浮在畫面最上層的 Windows 加分小工具。上課時開簡報、影片、小黑板都不會被蓋住，直接在小工具上幫學生加減分，還有抽獎機（不定量增強）和點數兌換獎勵。

## 下載與使用

1. 到右邊的 **Releases**，下載最新的 `ScoreWidget-x.x.x.exe`
2. 放到固定的資料夾（例如 `D:\加分小工具`），雙擊開啟
3. 第一次若出現藍色的「Windows 已保護您的電腦」，按 **其他資訊 → 仍要執行**

資料會存在 exe 旁邊的「加分小工具資料」資料夾（分數、頭貼照片、自訂音效都在裡面），整個資料夾帶著走，換電腦也能接著用。**換新版時，把新的 exe 放到同一個資料夾**，資料就會接著用。

## 操作方式

| 動作 | 方法 |
|---|---|
| 加分／扣分 | 按 ＋／−，或用滑鼠**左鍵／右鍵**點學生名字（展示模式點頭貼） |
| 按錯了 | 按 ↶，或按 `Ctrl + Z`（抽獎、兌換也能復原） |
| 抽獎 | 按 🎲；抽獎畫面按 `空白鍵` 抽，`Esc` 關閉 |
| 遊戲區 | 按 🎪（展示模式或學生小卡）：用點數換入場券，玩吃角子老虎機或刮刮樂 |
| 遊戲區開關 | 左下角或展示模式右上角的 🎪 |
| 學生小卡 | 點學生的分數：抽獎、兌換獎勵、送抽獎券、換頭貼、看最近紀錄 |
| 展示模式 | 把視窗最大化，或按左下角「展示模式」：大卡片＋頭貼，適合投影 |
| 迷你條 | 按標題列的長條圖示 |
| 音效開關 | 左下角喇叭（展示模式在右上角） |
| 置頂 | 標題列最左邊的圖釘 |

## 抽獎機（不定量增強）

- **獎池**：用「放幾顆球」決定機率，球可以是加分（0 分＝沒加碼）或獎品
- **可以存好幾組獎池**（例如建立期、穩定期），褪除時直接切換
- **不放回**：抽完一輪再重新裝滿，跟實體抽獎機一樣，天生有保底
- **放回**：每次機率都一樣
- **保底**：連續幾次沒加碼，下一次一定中
- **好行為基本分**：抽獎時先 +1，再看加碼
- **抽獎券**：可設定「每得到幾分送 1 張抽獎券」，也可以由老師直接送
- **四台機器**：扭蛋機、日本抽獎機、轉盤、骰子，**每台各自有自己的獎池**
- **扭蛋機**：抽的時候燈光變暗、鼓聲越來越緊張，扭蛋在機器裡跳上跳下，扭蛋滾出來才亮燈
- **日本抽獎機**：小朋友自己抓住把手轉一圈，球滾到盤子裡，中獎會搖鈴；老師也可以按按鈕幫忙轉
- **抽獎畫面右上角「✏️ 獎項」**：直接改獎項、顆數，馬上看到機率

## 🏙️ 虎尾大富翁（雛形）

- 上課好行為每 5 分（可調）自動得到 1 次擲骰機會
- 全班共用一張 24 格地圖，學生輪流擲 3D 骰子、走格子
- 格子：地產（買地、收租金）、機會、命運、銀行（存款利息、借錢）、保險公司、商店（需要 vs 想要）、法院（法治）、環保站（環境）、友善小站（性平）、幸運抽獎
- 金幣 💰 跟點數 ⭐ 分開；不會破產、不會出局，付不出來就先記成欠款
- 左下角或展示模式右上角的 🏙️ 打開；設定在「遊戲區／大富翁」分頁

## 🎡 遊樂場（8 種遊戲＋存錢機）

- 學生用點數換入場券（預設 10 點 1 張，點數會扣掉），換之前會提醒「不換的話，離某某獎勵還差幾點」（機會成本）
- 老師可以隨時開關遊樂場（上課關、獎勵時間開）
- 機率遊戲：
  - **吃角子老虎機**：押 1～3 張，押越大獎越大、越難中；也可以選「不拉」
  - **刮刮樂**：九宮格刮出 3 個一樣就中
  - **太空彈珠台**：按「發射」把珠子打上去，珠子撞彈跳器左右彈；落下時可以按左右擋板讓台子震動（只是好玩，不影響落點）；右邊會累積全班的落點，看得出「中間多、兩邊少」
  - **夾娃娃機**：粉紅玩具機台，搖桿會跟著動，夾到的娃娃會掉到出口；自己移動爪子；對準後夾中的機率可設定；沒夾到會提醒「用掉的拿不回來，下一次機率一樣」（沉沒成本）
  - **猜大小**：猜對獎金翻倍，最多 5 關，隨時可以收手；畫面直接顯示比較大／比較小各有幾張
  - **小動物賽跑**：全班一起押，熱門的容易贏但獎小，冷門的難贏但獎大
- 技巧遊戲：**打地鼠**（20 秒，越來越快，最後 10 秒超快）、**翻牌記憶配對**（翻錯越少分越多）
- **存錢機**：存 1 張入場券，7 天後領回 2 張；提早拿只能拿回 1 張（延宕滿足）
- 設定裡會算出每個遊戲「平均會多或少幾點」，方便老師設計

## 🔬 研究紀錄（背景記錄，學生看不到）

- 記下學生在遊樂場的每一個選擇：進場／離開、換入場券、選了哪個遊戲（以及上一次玩什麼、贏或輸）、每個決定的選項、機率、可得點數、成本、期望值、結果
- 設定 →「紀錄」可以看到每位學生的摘要：贏了留下、輸了換掉、選機率遊戲的比例、拉霸平均押幾張、猜大小平均第幾關收手、賽跑押的勝率、夾娃娃失敗後再夾的比例、存錢機的使用
- 「匯出 CSV」會存到資料夾裡的 `研究紀錄`，可以用 Excel 打開
- 按「復原」不會刪掉研究紀錄（學生做過的選擇還是算數）

## 等待與中獎特效

- 抽獎、轉盤、骰子、日本抽獎機、拉霸、刮刮樂揭曉前都會等久一點：燈光變暗、聚光、星光、鼓聲和心跳聲
- 等待時點螢幕會有音效、光點和畫面輕震，並累積「幫他加油」能量條；集滿會冒出「加油！」（只是加油，不會改變結果）
- 中獎有專屬背光；最大獎是旋轉的金色光芒、金幣雨、「大獎！」字樣和專屬音效

## 其他

- 頭貼：照片（自動裁成圓形）或 30 種卡通頭像
- 音效：內建加分、扣分、抽獎、兌換音效，加分和扣分可換成自己的 mp3
- 點數兌換獎勵：自訂獎勵和點數，卡片會顯示離下一個獎勵還差幾點
- 紀錄統計：每位學生的加分、扣分、抽獎、平均幾次一加碼、兌換次數、遊戲區次數與淨得（扣掉換入場券的點數）
- 每天自動備份一份，保留最近 30 天

## 開發

```
npm install
npm start      # 執行
npm run dist   # 打包成 exe
```

每次推送到 `main`，GitHub Actions 會自動打包並發佈到 Releases。
