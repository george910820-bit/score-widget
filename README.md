# 學生加分小工具

一直浮在畫面最上層的 Windows 加分小工具。上課時開簡報、影片、小黑板都不會被蓋住，直接在小工具上幫學生加減分，還有抽獎機（不定量增強）和點數兌換獎勵。

## 下載與使用

1. 到右邊的 **Releases**，下載最新的 `ScoreWidget-x.x.x.exe`
2. 放到固定的資料夾（例如 `D:\加分小工具`），雙擊開啟
3. 第一次若出現藍色的「Windows 已保護您的電腦」，按 **其他資訊 → 仍要執行**

資料會存在 exe 旁邊的「加分小工具資料」資料夾（分數、頭貼照片、自訂音效都在裡面），整個資料夾帶著走，換電腦也能接著用。**換新版時，把新的 exe 放到同一個資料夾**，資料就會接著用。

## 操作方式

| 動作 | 方法 |
|---|---|
| 加分／扣分 | 按 ＋／−，或用滑鼠**左鍵／右鍵**點學生名字（展示模式點頭貼） |
| 按錯了 | 按 ↶，或按 `Ctrl + Z`（抽獎、兌換也能復原） |
| 抽獎 | 按 🎲；抽獎畫面按 `空白鍵` 抽，`Esc` 關閉 |
| 拉霸 | 按 🎰（展示模式或學生小卡） |
| 學生小卡 | 點學生的分數：抽獎、兌換獎勵、送抽獎券、換頭貼、看最近紀錄 |
| 展示模式 | 把視窗最大化，或按左下角「展示模式」：大卡片＋頭貼，適合投影 |
| 迷你條 | 按標題列的長條圖示 |
| 音效開關 | 左下角喇叭（展示模式在右上角） |
| 置頂 | 標題列最左邊的圖釘 |

## 抽獎機（不定量增強）

- **獎池**：用「放幾顆球」決定機率，球可以是加分（0 分＝沒加碼）或獎品
- **可以存好幾組獎池**（例如建立期、穩定期），褪除時直接切換
- **不放回**：抽完一輪再重新裝滿，跟實體抽獎機一樣，天生有保底
- **放回**：每次機率都一樣
- **保底**：連續幾次沒加碼，下一次一定中
- **好行為基本分**：抽獎時先 +1，再看加碼
- **抽獎券**：可設定「每得到幾分送 1 張抽獎券」，也可以由老師直接送
- **四台機器**：扭蛋機、日本抽獎機、轉盤、骰子，**每台各自有自己的獎池**
- **扭蛋機**：抽的時候燈光變暗、鼓聲越來越緊張，扭蛋在機器裡跳上跳下，扭蛋滾出來才亮燈
- **日本抽獎機**：小朋友自己抓住把手轉一圈，球滾到盤子裡，中獎會搖鈴；老師也可以按按鈕幫忙轉
- **抽獎畫面右上角「✏️ 獎項」**：直接改獎項、顆數，馬上看到機率

## 吃角子老虎機（拉霸）

- 學生自己選：**不拉（保留點數）**、押小、押中、押大
- 押越大：花的點數越多、中獎機率越低、獎品越大
- 拉之前用圖示顯示「10 次大約中幾次」；沒中時會提醒「如果剛剛選不拉，現在會有幾點」（機會成本）
- 小朋友可以自己往下拉拉桿
- 設定裡會算出每個押注「平均每拉一次會多或少幾點」，方便老師設計

## 其他

- 頭貼：照片（自動裁成圓形）或 30 種卡通頭像
- 音效：內建加分、扣分、抽獎、兌換音效，加分和扣分可換成自己的 mp3
- 點數兌換獎勵：自訂獎勵和點數，卡片會顯示離下一個獎勵還差幾點
- 紀錄統計：每位學生的加分、扣分、抽獎、平均幾次一加碼、兌換次數、拉霸次數與淨得
- 每天自動備份一份，保留最近 30 天

## 開發

```
npm install
npm start      # 執行
npm run dist   # 打包成 exe
```

每次推送到 `main`，GitHub Actions 會自動打包並發佈到 Releases。
