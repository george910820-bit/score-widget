# 學生加分小工具

一直浮在畫面最上層的 Windows 加分小工具。上課時開簡報、影片、小黑板都不會被蓋住，直接在小工具上幫學生加減分。

## 下載與使用

1. 到右邊的 **Releases**，下載最新的 `ScoreWidget-x.x.x.exe`
2. 放到 **D 槽、隨身碟或雲端同步資料夾**（學校電腦有還原卡的話，不要放 C 槽桌面）
3. 雙擊開啟。第一次若出現藍色的「Windows 已保護您的電腦」，按 **其他資訊 → 仍要執行**

資料會存在 exe 旁邊的「加分小工具資料」資料夾，整個資料夾帶著走，換電腦也能接著用。

## 操作方式

| 動作 | 方法 |
|---|---|
| 加分 | 按 ＋，或用滑鼠**左鍵**點學生名字 |
| 扣分 | 按 −，或用滑鼠**右鍵**點學生名字 |
| 按錯了 | 按標題列的 ↶，或按 `Ctrl + Z` |
| 置頂／取消置頂 | 按標題列最左邊的圖釘 |
| 縮成迷你條 | 按標題列的長條圖示；迷你條上一樣可以左鍵加分、右鍵扣分 |
| 切換班級 | 標題列的下拉選單 |
| 新增學生 | ⚙ 設定 → 貼上名單（可以從 Excel 複製一整欄） |
| 移動視窗 | 拖曳標題列的空白處 |

## 設定裡還有

- 新增、改名、刪除班級
- 學生改名（分數會保留）、刪除學生
- 每次加減 1／2／3／5 分
- 依名單順序或分數高低排列
- 分數最低到 0
- 全班分數歸零
- 透明度、字體大小
- 開啟資料夾（每天自動備份一份，保留最近 30 天）

## 開發

```
npm install
npm start      # 執行
npm run dist   # 打包成 exe
```

每次推送到 `main`，GitHub Actions 會自動打包並發佈到 Releases。
